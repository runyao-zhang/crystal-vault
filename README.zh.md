# Crystal Vault（晶体库）

把一文件夹的 Markdown 卡片变成一座**能看的知识晶体库**：看清自己知道的东西长什么结构、
顺着连线读关系、边读文献边记、合上之前先自测一遍。

卡片就是普通的 Markdown，文件夹就是文件夹。没有任何东西被锁进数据库，也不出你的 vault。

## 为什么不直接用图谱？

图谱回答的是「**这张笔记和谁有关系**」——它以笔记为起点、连线是主角，**而文件夹根本不在图里**。
如果你的知识是按科目和章节组织的，图谱会把你所有东西搅成一团。
这正是很多人觉得它「好看但没用」的原因：**他们找不到自己组织知识的那条线。**

晶体库问的是另一个问题：「**这一块知识里有什么、长到什么程度了**」。它以文件夹为起点，
**结构本身就是主角**。

它不是更好的图谱，是**不同的起点**。

## 它做什么

- **一个文件夹 = 一颗晶体**。卡片目录下的每个子文件夹在环上就是一颗晶体，可以一层层钻进去。
- **双链变成形状**。正文里写 `[[另一张卡]]`，两张卡之间就出现一根线。故事线按连线拓扑把整颗晶体铺开。
  A→B 与 B→A **合成一条、两头带箭头**：一个箭头是单向，两个是互相。
- **孤岛是信号，不是错误**。既没链出去也没人链它的卡会被标出来——那是还没接进任何脉络的卡。
- **边读边记**。内置阅读器同时摊开 PDF / 图片 / Markdown，不离开页面就能建卡，
  还能让一张卡连回某份 PDF 的**某一页**。
- **结构就在旁边，不用切走**。阅读器里那颗「**结构窗**」把库的结构开成**你桌上的一扇窗**，
  和正在读的那一页并排——不是一块要切过去的屏。**切走是「离开」**：回来得重新找到刚才那行。
  一扇窗只是**看一眼**。
  在窗里拖一根线连两张卡，它会往笔记里真写一条 `[[双链]]`，当场可以填一句**为什么连**，留一次撤销。
- **先想再看**。回忆模式下卡片内容默认遮住，点一下才显示；复习模式全部摊开。

## 安装

在 *设置 → 第三方插件 → 浏览* 里搜 **Crystal Vault**。

手动装：从 [最新 Release](https://github.com/runyao-zhang/crystal-vault/releases/latest) 下载
`main.js` / `manifest.json` / `styles.css`，放进 `<你的 vault>/.obsidian/plugins/crystal-vault/`，
然后在 *设置 → 第三方插件* 里启用。

## 上手

1. 在插件设置里把**卡片目录**指到你放笔记的那个文件夹。
2. 点侧边栏那颗宝石图标（或运行命令 **Crystal Vault: Open**）。
3. 在卡片目录里建一个子文件夹——那就是一颗晶体。
4. 按下面的格式写一张卡，再用 `[[双链]]` 把它连出去。

## 卡片格式

```markdown
---
概念: 一句话说清它是什么
来源: 哪本书 / 哪节课 / 哪份文献
tags: [科目, 类型]
---

先用自己的话说清它是什么……

接着看 [[02-下一张]] 连过去的原因就写在后面

==高亮== 的部分会被抽成自测点。
```

| 字段 | 在库里长什么样 |
| --- | --- |
| （文件名） | 卡片的标题，`卡片-` / `卡片_` 前缀会自动剥掉 |
| `概念` | 面板顶部那一行 |
| `来源` | 悬停浮层里的「来源」 |
| `tags` | 卡面上最多显示前 6 个 |

**四条让库活起来的习惯**：至少连一次（不然是孤岛）· 连的时候写下理由 ·
用编号前缀控制顺序（`01-` `02-`）· 想自测的地方用 `==高亮==`。
